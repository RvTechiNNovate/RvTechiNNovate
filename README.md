## 🧠 What I Build

### 🤖 AI Agents
Building AI agents that can understand user intent, decide which tool or workflow to execute, and interact with external APIs and systems.

### 📚 RAG Applications
Designing document-based AI systems with:

`Document → Chunking → Embeddings → Vector Search → Retrieval → LLM → Response`

with a focus on retrieval quality, hallucination reduction, evaluation, and observability.

### 🔎 NL2SQL
Building systems that convert natural-language questions into SQL queries, execute them against databases, and return structured results and visualizations.

### 📄 Intelligent Document Processing
Using LLMs to extract structured information from documents and automate workflows such as form filling and document analysis.

### ⚡ Local / Offline LLM Deployment
Working with local LLM deployments using technologies such as **vLLM** for applications where data privacy and controlled infrastructure are important.
